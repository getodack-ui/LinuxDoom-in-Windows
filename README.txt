DOOM (linuxdoom-1.10) -> Windows / Visual Studio
=================================================

Исходники: официальный релиз id Software (GPL, см. LICENSE.TXT).
Из оригинала убраны X11, OSS-звук и сокеты, добавлен слой Win32 (GDI).
Никакого CMake/Make: открываешь DoomWin.sln и жмёшь сборку.

ГОТОВАЯ СБОРКА (БЕЗ VISUAL STUDIO)
  run\doom_mingw.exe - уже собран MinGW (32-бит, статически, без лишних
  DLL). Положи рядом doom1.wad и запускай. Visual Studio для этого не нужна.

СБОРКА В VISUAL STUDIO
  1. Открой DoomWin.sln в Visual Studio 2019/2022 (нужна нагрузка
     "Разработка классических приложений на C++").
  2. Платформа: x86 (Win32). x64 НЕ поддерживается - в коде Doom 1993 года
     указатели хранятся в int, на 64 битах он падает.
  3. Положи свой doom1.wad (или doom.wad / doom2.wad / plutonia.wad /
     tnt.wad) в папку run\ . Туда же собирается doom.exe (Release) и
     doom_debug.exe (Debug). F5 запускает игру с рабочей папкой run\ .
  4. Если появятся ошибки сборки - пришли текст ошибки, поправим.

УПРАВЛЕНИЕ (как в оригинале)
  Стрелки - ходить/поворот, Ctrl - огонь, Пробел - открыть/использовать,
  Shift - бег, Alt + стрелки - боковой шаг, 1-7 - оружие, Tab - карта,
  Esc - меню, F1..F12 - функции меню.
  Мышь захватывается в игре (в меню свободна): левая - огонь,
  правая - боковой шаг, средняя - вперёд.
  Alt+Enter - полный экран.  Alt+F4 / крестик - выход.

ПАРАМЕТРЫ КОМАНДНОЙ СТРОКИ
  -2 / -3 / -4     размер окна (x2, x3 по умолчанию, x4)
  -fullscreen      старт в полноэкранном режиме
  -nomouse         без мыши
  -warp E M        сразу на уровень (например: -warp 1 1)
  -skill N, -file pwad, -devparm  и остальное из оригинала
  Настройки сохраняются в default.cfg рядом с запуском.

ЧТО НЕ СДЕЛАНО
  - Звука и музыки нет (заглушки в src\win32\i_sound.c).
  - Сетевой игры нет (src\win32\i_net.c, только одиночная).
  - Демо старых версий (109) оригинальный код не проигрывает.

ЧТО ИЗМЕНЕНО В ОРИГИНАЛЬНЫХ ФАЙЛАХ (всё остальное нетронуто)
  w_wad.c   : убраны самодельные strupr/filelength и O_BINARY=0
              (на Windows WAD обязан читаться в двоичном режиме)
  m_menu.c  : O_BINARY при чтении описаний сохранений
  d_main.c  : конфиг default.cfg вместо ~/.doomrc, _mkdir вместо mkdir
  d_net.c   : I_Yield() в цикле ожидания тика (не грузить процессор на 100%)
  Заголовки-заглушки POSIX: src\compat\ (unistd.h, values.h, alloca.h,
  win_compat.h - подключается ко всем файлам через /FI).

ПРОВЕРЕНО
  Собрано кросс-компилятором MinGW (i686) и запущено под Wine с Freedoom:
  меню, рендер, клавиатура, Alt+Enter работают.
  Сборка именно в Visual Studio (MSVC) НЕ проверялась.
